## 🎯 Overview

**NIRMAD** (निर्माण धमतरी) is a sophisticated Flutter-based government application designed to streamline infrastructure project management across **Dhamtari District**. The system enables seamless coordination between various administrative levels for tracking, managing, and reporting on construction projects under government schemes.

### 🏗️ Covered Blocks

| Block | Hindi Name | Gram Panchayats |
|:------|:-----------|:----------------|
| 🏘️ Dhamtari | धमतरी | 100+ |
| 🏘️ Kurud | कुरूद | 80+ |
| 🏘️ Nagri | नगरी | 70+ |
| 🏘️ Magarlod | मगरलोड | 60+ |

## ✨ Features

### 📊 Dashboard & Analytics

- 📈 Real-time project statistics with interactive charts
- 🗺️ Geographic visualization with Flutter Map integration
- 📉 Financial tracking and expenditure analysis
- 🎯 Progress monitoring across all project phases

### 📋 Project Management

- ➕ Create new infrastructure projects with detailed metadata
- 📝 Multi-step form wizard with validation
- 📸 Photo documentation with before/during/after capture
- 📍 GPS-based location tagging with Geolocator
- 📄 PDF report generation for official documentation

### 🔔 Notifications & Updates

- 🔔 Push notifications via Firebase Cloud Messaging
- 📢 Awesome notifications for local alerts
- 📰 Real-time project status updates

### 📁 Document Management

- 📤 File upload and download capabilities
- 📑 Document categorization and tagging
- 🔗 Cloud storage integration with Firebase Storage
- 📥 Offline file caching with Hive

### 🌐 Multilingual Support

- 🇮🇳 Hindi (हिंदी) - Primary
- 🇬🇧 English - Secondary
- 🔄 Dynamic language switching

## 🚀 Getting Started

### 📋 Prerequisites

- ✅ Flutter SDK 3.9+
- ✅ Dart SDK 3.9+
- ✅ Firebase CLI
- ✅ Android Studio / Xcode
- ✅ Git

### 💻 Installation

```bash
# 1️⃣ Clone the repository
git clone https://github.com/your-org/nirmadapp.git
cd nirmadapp

# 2️⃣ Install dependencies
flutter pub get

# 3️⃣ Generate code (if needed)
flutter pub run build_runner build

# 4️⃣ Run the app
flutter run
```

### 🔧 Development Commands

```bash
# 🧹 Clean build
flutter clean && flutter pub get

# 📱 Run on specific device
flutter run -d chrome          # Web
flutter run -d android         # Android
flutter run -d ios             # iOS

# 🏗️ Build release
flutter build apk --release    # Android APK
flutter build web --release    # Web build
```
